# Data Structure Testing and Benchmarking Toolkit

This project contains educational implementations of fundamental data structures (`DynamicArray`, `MyLinkedList` with `tail` optimization, `MinHeap`) that allow for precise tracking of operations (steps, moves, comparisons), as well as a comprehensive suite of performance benchmarks and unit tests.

---

## 1. Environment Requirements
* **Java SDK**: JDK 17 or higher
* **Apache Maven**: Version 3.8+
* **Python**: Version 3.8+ (the `pandas` and `matplotlib` libraries are required for generating plots)

---

## 2. Project Compilation and Build

To clean the project and compile the source code, run the following command:
```bash
mvn clean compile
