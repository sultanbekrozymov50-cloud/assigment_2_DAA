# Data Structures Benchmark & Testing Framework

A Java performance benchmarking suite and data structure collection implementing `DynamicArray`, `MyLinkedList` (with `tail` pointer optimization), and `MinHeap` with precise operation metrics tracking (`steps`, `moves`, `comparisons`).

---

## 1. Project Requirements
* **Java SDK**: JDK 17 or higher
* **Build Tool**: Apache Maven 3.8+
* **Python** (optional for plotting): Python 3.8+ with `pandas` and `matplotlib`

---

## 2. Compilation and Build
